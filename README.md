# Muotea Tap

## How do I install these formulae?

`brew install muotea/tap/<formula>`

Or `brew tap muotea/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "muotea/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
